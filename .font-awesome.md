# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Self-hosted SVG files, one per icon, in `src/icons/*.svg`, imported as React components through `vite-plugin-svgr` (`import XSvg from './x.svg?react'`) and wrapped by `makeIcon` in `src/icons/index.tsx`. **No `@fortawesome/*` npm packages, no Kit, no CDN** — the project convention is "use the icon registry at `@/icons`; don't install `@fortawesome/*`".
- **Version:** 7.2.0 for most of the registry (69 of 124 files), with a few 7.3.x (including the seven Solid/Regular files) and 6.6.0 files. Add new files at the **latest 7.x**.
- **License:** Pro (the vendored files carry the Font Awesome Pro license header; a handful are Free).
- **Families:** classic
- **Weights vendored:** Light (the default, most of the registry), Solid (`house-solid`, and `circle`, `circle-check`, `slash-forward`), Regular (`circle`, `circle-check`, `clock`, `house`). The Solid/Regular set was fetched 2026-09-23 at 7.3.1 for the Compass LMS course rail.

## Defaults

- **Style:** light — the registry is Font Awesome 7 Pro **Light** throughout (see `CLAUDE.md`, Stack → Icons). Solid and Regular files are added only where a design names them.
- **Family:** classic

## Import Pattern

- Vendor the SVG file into `src/icons/` — **fetched from the Font Awesome API**, never hand-drawn or reconstructed: `fa icons --json --version <v> --name <icon> --svg-format html --svg-family-style classic,<style>` (needs `fa login`). The API returns bare markup; add the Pro licence comment after the `<svg>` tag, matching the other files.
- Register it in `src/icons/index.tsx`:
  - `import CircleCheckSvg from './circle-check.svg?react'`
  - `export const CircleCheck = makeIcon(CircleCheckSvg) // FA: circle-check`
- Use it from anywhere: `import { CircleCheck } from '@/icons'` → `<CircleCheck size={15} aria-hidden />`.

## Conventions

- **File names are the FA icon name**, light weight by default (`circle-check.svg`). A non-light weight takes a suffix, matching the existing `house-solid.svg`: `circle-solid.svg`, `circle-regular.svg`.
- **Export names are PascalCase of the icon name**, with the weight appended for non-light variants: `HouseSolid`, `CircleRegular`.
- `makeIcon` renders `fill: currentColor`, so colour comes from the parent's CSS `color`; size is the `size` prop (default 16).
- Some registry entries map a friendly export name to a different FA icon (e.g. `Circle` is FA `circle-dashed`); the trailing `// FA: …` comment records the real name. Check it before assuming an export is the icon its name suggests.
