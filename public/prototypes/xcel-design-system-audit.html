Atlas vs. Compass — Typography & Color Audit

October 27, 2026 · prepared by Jillienne

Sources reviewed

  • Atlas: Figma "Atlas Style Guide" — global color palette frame (node 3-1032) and status-color legend (node 270-39)
  • Compass: compassdesignsystemv5 1.html — Colors and Typography sections (inlined CSS custom properties, v5)

TL;DR

  • The underlying color hex values already match almost everywhere between Atlas and Compass — this is a naming/structure problem, not a color problem.
  • Typography is where the two systems genuinely diverge — different font families, different scales, different weight conventions.
  • Atlas also has a few internal inconsistencies (independent of Compass) worth cleaning up while this is being discussed.

1b. Gaps / open questions

  • Compass defines a dedicated "Rubi" accent — terracotta #B4552F plus a soft tint (#F7EDE7 / rgba(180,85,47,.08)) — called out as a hard brand rule ("Terracotta = Rubi, the coach"). Nothing in the two Atlas frames reviewed defines an equivalent token.
  • Compass's --c-review (#C08A2E, fill/dot only, never text) and its ink/muted/faint text tiers (#1F1D18 / #5B5560 / #706B63) don't have obvious counterparts in the two Atlas frames reviewed — worth checking Atlas's broader neutral scale for these.
  • Atlas's neutral set (separate from the primary/secondary/tertiary/accent scale) has duplicate-looking tokens that resolve to different values: Neutral/Darkest = #292929 vs Neutral/darkest = #0A0A0A. (Neutral/Neutral vs Neutral/neutral are at least the same value, #A2A2A2, just inconsistently cased.)

1c. Naming convention mismatch — the real conflict

  • Atlas: numeric brand scale — primary/100…900, secondary/100…900, tertiary/100…900, accent/1-3, plus a separate neutral/* set.
  • Compass: semantic, role-based names — --c-steel, --c-slate, --c-surface, --c-ink/muted/faint, --c-emphasis-fill, --c-border-interactive, --c-pass/review/error, etc.
  • Role-based names read closer to Compass's "rules that never bend" (e.g. "emphasis is a role, not a surface") and are easier to apply correctly in product code; numeric scales are more flexible for future tints/shades. Either way, the team needs one published token map so primary/500 and --c-steel are never two separate sources of truth for the same hex.

2. Typography

2a. Font families

  • Atlas headings: two parallel systems, both literally labeled "Heading 1–4" — a serif set (named "Playfair" on its swatch, "Playfair 2" in the style-guide table, and described as "DM Serif Display" in the usage copy — three different names for what appears to be one typeface) and a separate Open Sans heading set.
  • Atlas body/UI: Open Sans.
  • Compass headings: Source Serif 4. Compass body/UI: Inter. Compass code: JetBrains Mono.
  • Conflict: no shared typeface between the two systems — different serif (Playfair/DM Serif Display vs. Source Serif 4) and different sans (Open Sans vs. Inter).

2b. Internal Atlas naming to resolve before merging

  • The font card is internally inconsistent: shown as "Playfair", described as "DM Serif Display" in the usage guidance, and labeled "Playfair 2" in the heading-styles table. Which is the real typeface?
  • Atlas's serif Heading 2 (32px/34px) and Heading 3 (27px/29px) are both tagged with the same scale token "4xl" — two different sizes sharing one token name.
  • Atlas's published design variable font size/heading/2xl = 28, but the on-canvas style-guide table labels that same 28px row "3xl" instead — the token numbering in the variables panel doesn't match the label designers and engineers actually see in the guide.

Observations

  • Atlas's scale has more, smaller steps (two separate 4-step heading ladders plus a 4-step paragraph ladder); Compass compresses everything into 6 named roles (display/h1/h2/body/sm/eyebrow).
  • Font weight convention differs: Atlas headings default to Bold/700 (with SemiBold/Regular variants also defined under the Open Sans heading set); Compass headings use 500 (display/h1) or 600 (h2) — never 700.
  • Line-height ratios differ: Atlas's paragraph set is tighter (roughly 1.25–1.4x depending on size) vs. Compass body at 1.55x; headings are closer (both land near 1.2x).
